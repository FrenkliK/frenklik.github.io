# Applyboard — Job Application Tracker

A small, responsive job-search tracker with a kanban view, application metrics, search, editing, and browser-local persistence.

## Run

Open `index.html` in a modern browser. No build step, dependencies, account, or server are required. Data is stored in the browser's local storage and stays on that device.

## Features

- Wishlist, Applied, Interview, and Offer stages
- Add, edit, delete, and search applications
- Application, active pipeline, interview, and response-rate summary
- Responsive layout and sample data reset

## Next steps

For a production version, add a backend, authenticated accounts, per-user authorization, database migrations, input validation on the server, automated tests, and a clear privacy/data-retention policy. The local demo is not a multi-device or backup solution.

## Stack

HTML, CSS, JavaScript, Web Storage API.
